### 对于八股的建议

1. 如果面试官考的如果是常规八股，我们要做到的是，结合工作中的例子，来举例论证这个知识点，因为这样的八股往往可能就是一个概念，没有太多可以深入专研的意义。
2. 如果考的是一些比较难的八股，那么我们就一定要懂它的原理了，这种情况下，往往问的会比较深入，这种情况下，除非是大厂面试，会一直往更底层问，直到我们回答不出来为止，但是一般社招其实不会问的太过深入，这都是很少数的情况。

我认为，对于这种较为复杂的知识点，无论我们是
